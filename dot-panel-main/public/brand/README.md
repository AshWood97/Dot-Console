# Dot Console brand kit

Original mark for this local customization: a warm-white command chevron and a mint assistant dot on a deep pine rounded tile. The 32-unit SVG uses only a rectangle, path and circle. It contains no upstream icon, OpenAI knot, Codex logo, external image or font. The same geometry is legible at 16 and 32 pixels.

Dot Console is the product name. The assistant's existing personal name remains separate and unchanged.

`favicon.svg` is the canonical code-native vector. `generate.py` creates all SVG variants; `render.py` produces PNG/ICO copies and review sheets from those vectors. Wordmarks use system sans. Marks include an accessible title; use empty image alt text next to the visible product name.

Colors: pine #173E32, warm white #F4F7F0, mint #9AD6B3. See contrast.json for computed contrast. All assets remain AGPL-3.0-only as part of this modified application; existing upstream copyright, LICENSE and third-party notices are preserved elsewhere in the repository.
